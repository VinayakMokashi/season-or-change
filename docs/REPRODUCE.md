# Reproducing the results

Run all commands from the repository root.

- **Tables, statistics and figures** are regenerated by the scripts below from
  the files in `results/`. `figures/pretraining_examples.*` also streams a sample
  of the pretraining archive. The exception is `figures/change_ratio_histogram.png`
  (see section 2).
- **The new probe sweep** (`results/probes/`) can be rerun end to end on a CPU.
- **Earlier runs** are stored as their raw outputs, together with the scripts or
  settings that produced them:
  - the pretraining logs (`results/pretraining/`);
  - our original single-seed evaluation (`results/original_eval/`);
  - the Colab and BigEarthNet probes of the released checkpoints
    (`results/earlier_runs/`). The Colab result is a JSON transcription of that
    run's printed output.

## 1. Evaluation (CPU, about an hour)

```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install torch==2.14.1 torchvision==0.29.1 --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt
python scripts/download.py                              # data + all encoder weights (~0.8 GB)

python src/probe/run_probes.py --dataset eurosat  --data_dir data/eurosat/EuroSAT_RGB
python src/probe/run_probes.py --dataset ucmerced --data_dir data/ucmerced/UCMerced_LandUse/Images
python src/analysis/probes.py                           # tables, paired tests, hypotheses, figures
```

`run_probes.py` writes one JSON summary and one file of per-image predictions
per backbone to `results/probes/<dataset>/`. It caches features in
`cache/features/`, keyed by the weights and the exact image list. A rerun then
skips feature extraction and only retrains the probes, which takes a few minutes.

The UC Merced split in `splits/` was generated with
`python src/probe/make_ucmerced_split.py --root data/ucmerced/UCMerced_LandUse/Images`
(20 test images per class, seed 0).

## 2. Figures

```bash
python src/analysis/pretraining.py                      # figures/pretraining_loss.*  (from results/pretraining)
python src/analysis/pretraining_examples.py             # figures/pretraining_examples.*  (streams ~25 MB of the archive)
python src/analysis/failure_examples.py                 # figures/failure_examples.*  (from results/probes predictions)
```

`src/analysis/probes.py` writes `figures/probe_accuracy*` and
`figures/component_steps*`.

`figures/change_ratio_histogram.png` comes from our CACo pretraining run. It is
the change-ratio panel of the plot that the reference code's `HistogramCallback`
writes to `histogram_caco/` during training.

## 3. Pretraining (GPU)

The four encoders were each trained on one GPU with the reference
implementation in `third_party/caco_upstream`. Set up the environment described
in `requirements-pretrain.txt`, download the pretraining archive, and launch:

```bash
python scripts/download.py --pretrain                   # 2,000 locations x 10 dates (1.5 GB)
bash scripts/pretrain.sh seco                           # also: teco, caco, moco
```

Each run writes `logs/<run>/metrics.csv` (the per-epoch format of
`results/pretraining/`) and
`checkpoints/<run>/resnet18_<mode>_geo_10k_400.pth`. To probe a new encoder:

1. Copy its `.pth` into `<dir>/ours_10k/` under a separate directory `<dir>`,
   using the names listed in `src/probe/backbones.py` (including `moco-10k`).
2. Run `run_probes.py --ckpt_dir <dir> --backbones <name>`.

Keep `checkpoints/` for the released files that `scripts/download.py` verifies.
Note that `src/analysis/probes.py` tabulates only the backbones in its `ROWS`
list.

Logged training time: SeCo 4.6 h, TeCo 9.2 h, CACo 9.1 h, MoCo 23.9 h.

To resume an interrupted run, pass `--resume_from_checkpoint <periodic .ckpt>`.
For CACo, note that the reference code keeps the per-item change estimates
(moving averages and mixture labels) in memory, not in the checkpoint, so they
are rebuilt from scratch after a resume.

## 4. BigEarthNet probe of the authors' checkpoints (GPU)

```bash
python experiments/bigearthnet/train_bigearthnet.py --data_dir data/bigearthnet --download
```

On the first run, `--download` fetches BigEarthNet-S2 v1.0 and its splits from
Zenodo record 12687186 (about 70 GB); later runs can omit it. The script is a
cleaned version of the one that produced
`results/earlier_runs/bigearthnet_100k_probe.log`, with the same settings.

## 5. Colab probe of the authors' checkpoints

```bash
python experiments/eurosat_colab_probe/eurosat_probe.py --data_dir data/eurosat/EuroSAT_RGB
```

This reproduces the BN-adapt protocol of report Table IV. The script prints its
results; `results/earlier_runs/eurosat_100k_colab_probe.json` records the printed
output of our original Colab run.
